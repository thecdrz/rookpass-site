Feature comparison

Clear tiers. Same security model.

RookPass Free includes the full personal password manager, including themes and in-app language choice. RookPass Pro adds advanced controls for users who want more structure, scale, or operational features. Eligible new subscribers can start Pro with a 7-day free trial.

Free

Core password management included.

AutoFill, passkeys, TOTP, themes, app language choice, import/export, and encrypted sync are part of the base product.

Pro

Additional operational tools.

Multiple vaults, SSH keys, bulk actions, deeper history, and encrypted sharing extend the product when you need more control.

Security

No separate privacy tier.

Both plans share the same local-first, zero-knowledge security architecture.
